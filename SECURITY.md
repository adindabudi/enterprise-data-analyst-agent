# Security

Report suspected vulnerabilities privately through GitHub's private
vulnerability reporting on this repository's Security tab. Do not disclose them
in public issues, pull requests, or discussions before coordinated remediation.

Reports and reproduction material must not include production prompts, tokens,
or files. Security fixes are supported on the latest tagged release.

Generated code runs only in task-scoped ACA Sandboxes with default-deny egress.
Do not place credentials, delegated tokens, hidden reasoning, or Foundry response
identifiers in prompts, Redis, manifests, logs, artifacts, or the sandbox.
